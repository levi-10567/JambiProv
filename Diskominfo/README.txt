PEMERINTAH PROVINSI JAMBI — CIVIC UI REWORK V5
====================================================

CARA MENJALANKAN
1. Extract nahnah-ui-rework.zip
2. Open folder nahnah di VS Code
3. Klik kanan index.html
4. Open with Live Server
5. Buka http://127.0.0.1:5500/index.html

FITUR
- Static HTML / CSS / Vanilla JS
- Tidak butuh PHP / XAMPP
- Semua navigasi utama dan submenu menuju halaman internal
- Search halaman dan berita internal
- Halaman berita detail
- Halaman video internal dengan embedded player
- Halaman galeri
- Halaman dokumen internal
- Halaman kabupaten/kota internal
- Responsive desktop / tablet / mobile
- Semua gambar utama disimpan lokal di assets/img
- Civic UI V5: visual lebih bersih, profesional, dan mudah dibaca
- Akses layanan resmi berada langsung di bawah hero beranda
- Navigasi aktif, fokus keyboard, dan reduced-motion yang lebih aksesibel

CATATAN
Konten website disusun berdasarkan struktur dan informasi publik Pemerintah Provinsi Jambi.
Teks panjang diringkas/parafrase agar mudah dibaca dan siap dikembangkan ke backend/CMS.
